This site used to be a single HTML file. It said hello, pointed at [[unraveled-makes]], and that was that. But I kept wanting somewhere to put the <mark>in-between stuff</mark> — the notes, the half-finished thoughts, the things I figured out at 11pm and would otherwise forget.

So: a digital garden. Notes instead of Posts-with-a-capital-P. Everything links to everything with `[[wiki links]]`, like my Obsidian vault, because that's how my brain files things anyway.

A few things you might notice:

- Pages link to each other, and each note lists its **backlinks** at the bottom — so you can wander in any direction.
- If you type on your keyboard while you're here, the site <mark>thocks</mark> like a mechanical keyboard. This serves no purpose. I love it. (There's a `sound: off` switch in the footer if you don't.)
- It's built with [Eleventy](https://www.11ty.dev/), markdown files, and a GitHub Action. The whole thing is [on GitHub](https://github.com/danaadylova/danaadylova.github.io).
