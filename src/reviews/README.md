# My book reviews

One Markdown file per book. They show up as "dana's notes" when the book is opened on /books.

```markdown
---
book_id: 19161852   # the number in the book's Goodreads URL: goodreads.com/book/show/19161852
date: 2026-09-20
---
The first hundred pages are a slog and then it absolutely **wrecks** you…
```

File names don't matter (e.g. `the-fifth-season.md`). A review for a book that isn't on the shelf is ignored with a build warning.
